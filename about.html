About · Course demo

A demo shop, built to learn.

ShopBoard looks like an online shop, but it is a demo built for a course. Nothing is for sale, nothing ships, and no payment is ever taken.

This is a demo. You can browse, fill a cart and try the forms, but there are no real orders or payments, and the forms send nothing.

What you can try

  • Search, filter and sort the products on the shop page. “Default” brings back the original order.
  • A cart saved in your browser. Add products, change quantities with + and −, or remove them. The cart is still there when you come back, and the count in the header follows along, even in other tabs.
  • Light and dark themes. Use the System / Light / Dark switch in the header. System follows your device setting.
  • Demo forms. The Join form and the contact form check what you type, then tell you that nothing was sent.
  • A demo checkout. It takes no payment and places no order.

How it’s built

ShopBoard is a static website. There is no backend and no database: the product list is a JSON file that comes with the site, and everything else happens in your browser.

  • HTML and CSS, mobile-first, with no CSS framework.
  • TypeScript with strict on, written as ES modules, with no JavaScript framework.
  • Vite for the development server and the build.
  • GitHub Pages hosts the built site.

The code is split into small modules, one folder per feature (products, cart, theme and so on), and each kind of file has one job. The product photos are free photos from Pexels, listed on the Photo credits page.

Source code

All of the code is on GitHub at github.com/zainabwatfa/shopboard. It is released under the MIT License, so you can read it, reuse it and change it, as long as you keep the license notice.
